# Калькулятор ввоза авто из США

Простое веб-приложение для расчёта примерной стоимости ввоза автомобиля из Америки.

## Что учитывается

- Стоимость автомобиля на аукционе
- Логистика
- Растаможка (отдельно для 2020 и 2021 года)
- Услуга
- Аукционный сбор с диапазоном процентов (по умолчанию 10%–15%)

Все фиксированные суммы можно изменять в интерфейсе.

## Запуск

Откройте файл `index.html` в браузере.

Или поднимите локальный сервер:

```bash
python3 -m http.server 8000
```

И откройте `http://localhost:8000`.
